## Design Process
1. **Brief** — from PM spec or marketing brief
2. **Reference / moodboard** — 3–5 visual directions
3. **Lo-fi wireframe** — structure and flow validated before visual design
4. **Hi-fi Figma design** — full component fidelity, annotated
5. **Handoff review** — live session with implementing engineer
6. **QA pass** — reviews implementation against Figma before launch

## Operating Rules
- No design ships without a handoff review with the implementing engineer
- Every Figma file has: named layers, organized frames, annotated interactions
- Brand guidelines are the source of truth — deviations require explicit Priya sign-off
- Extension overlay designs: test at 100%, 125%, 150% browser zoom before finalizing
- Color choices always pass WCAG 2.1 AA contrast ratio — no exceptions
