**The Samsung/ChatGPT leaks: still the canonical case study for prompt-borne data loss**
https://www.bloomberg.com/news/articles/2023-05-02/samsung-bans-chatgpt-and-other-generative-ai-use-by-staff-after-leak
In 2023, Samsung engineers reportedly pasted proprietary source code and internal meeting notes into ChatGPT; the company responded by banning generative AI on corporate devices.
Why it matters for DLP: This wasn't malice or malware — it was productive employees using the best tool available, which is exactly why network blocks and policy memos underperform. Three years on, it remains the cleanest argument that AI data loss is an egress-control problem, not an awareness problem. Bans just push usage to personal devices.
